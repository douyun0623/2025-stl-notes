## 저장소 구성

- `2025 STL/`: 학기 중 누적 실습 프로젝트
- `강의 필기/`: 주차별 수업 기록
- `연습/`: 작은 기능 단위 실험
- `STL 중간고사/`, `중간답/`: 중간 문제와 풀이
- `STL 기말고사/`, `STL 기말고사 (1)/`: 기말 문제 풀이

총 6개의 Visual Studio 솔루션이 있으며 각 프로젝트는 독립 실행되는 콘솔 프로그램입니다.

필기·실습·답안은 모두 김도윤의 개인 작업입니다. 일부 과거 커밋의 작성자명은 학교 PC의 로컬 Git 설정 때문에 다르게 기록되어 있습니다.

## 빌드 및 실행

- Visual Studio 2022
- MSVC `v143`
- 프로젝트 설정 기준 `/std:c++latest`
- 권장 구성: `Release | x64`

Developer PowerShell for VS 2022에서 대표 솔루션을 빌드하는 예시입니다.

~~~powershell
msbuild ".\STL 기말고사 (1)\STL 기말고사.sln" /t:Rebuild /p:Configuration=Release /p:Platform=x64
~~~

파일을 읽는 예제는 실행 파일 위치가 아닌 해당 프로젝트 폴더를 작업 디렉터리로 사용해야 합니다.

누적 실습의 기본 실행 경로는 추적 중인 `강의저장.txt`에 내용을 덧붙이므로, 실행 전 별도 복사본을 사용하는 편이 안전합니다.

## 빌드 확인

Visual Studio 2022/MSBuild에서 6개 솔루션의 `Release | x64` 빌드를 확인했습니다. 대표 기말 실습은 포함된 입력 파일을 읽어 12,355개 객체와 중복 탐색 결과를 출력했습니다.

## 학습용 코드의 성격

커스텀 `STRING`은 자원 소유와 복사·이동 동작을 관찰하기 위한 수업용 구현입니다. 일부 버전에는 대입·비교·const 반복자 동작 등 보완할 부분이 남아 있어 범용 문자열 구현으로 제시하지 않습니다.

일부 필기와 소스는 CP949로 저장되어 GitHub에서 한글이 깨져 보일 수 있으며, 저장소에는 실습용 대용량 입력 데이터도 포함되어 있습니다.
