# C++ STL Notes | 컨테이너·알고리즘·메모리 학습 기록

2025년 1학기 STL 수업의 필기, 실습 코드, 중간·기말 문제 풀이를 모은 저장소입니다.

완성된 애플리케이션보다는 C++의 자원 관리와 STL 구성 요소를 직접 구현하고 실험한 과정을 보여 주는 보조 포트폴리오로 분류합니다.

## 학습 범위

- RAII와 `std::unique_ptr`를 이용한 동적 메모리 관리
- 복사·이동 생성자와 대입 연산자
- `vector`, `list`, `set`, `multiset`, `array` 등 표준 컨테이너
- 반복자, 역방향 반복자, 스트림 반복자
- `sort`, `find`, `equal_range`, `copy`, `remove` 등 STL 알고리즘
- C++20 ranges와 concepts
- 텍스트·바이너리 파일 입출력과 직렬화 실습

## 참고 사항

- 일부 소스와 필기는 CP949로 저장되어 GitHub 웹 화면에서 한글이 깨질 수 있습니다. Visual Studio에서는 원래 인코딩으로 열 수 있습니다.
- 시험용 입력 데이터에는 약 12~50 MB 크기의 파일이 포함되어 있습니다.
- 일부 시험 코드는 전체 `int` 범위를 순회하는 계산처럼 의도적으로 실행 시간이 긴 실험을 포함하므로, 모든 실행 파일을 일괄 실행하지 않았습니다.
- 현재 학기 말 예제의 `save()` 함수는 실행 시 강의 누적 파일에 내용을 덧붙입니다. 소스 확인 없이 실행하면 저장소 파일이 변경될 수 있습니다.
